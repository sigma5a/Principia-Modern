# Principia: A Living Edition

A modern, readable web edition of Isaac Newton's *Philosophiæ Naturalis Principia Mathematica*.

**Read it online:** https://sigma5a.github.io/Principia-Modern/

## What's inside

- The complete 1846 Andrew Motte English translation: Books I, II and III, plus the front matter
- Newton's *System of the World*
- The original geometric illustrations
- Modern summaries and experiments, kept clearly separate from the historical text

## Run it locally

No build step needed. Download or clone this repo and open `index.html` in your browser.

## Files

| Path | What it is |
| --- | --- |
| `index.html` | Home page |
| `edition/` | The full text, split into books |
| `edition/images/` | The original diagrams |
| `reader.css`, `reader.js` | Reader styling and behavior |

The Motte translation is in the public domain.
